# ReportKit Showcase

This directory contains small public preview screenshots for the GitHub README.

The screenshots are generated from ReportKit's internal visual regression samples and show the default `executive-cn` template in realistic report pages. They are intentionally lightweight preview assets for the public repository README, not the full visual regression suite and not part of the minimal npm wrapper package.

The default formal report path should favor paragraphs, normal lists, centered tables, figures, equations, and code blocks. Metric cards, glossary-style blocks, checklists, and callouts remain compatibility or explicitly requested features rather than the default showcase style.
